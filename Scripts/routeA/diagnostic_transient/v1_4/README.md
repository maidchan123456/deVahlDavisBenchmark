# Route A diagnostic persistence v1.4

Supersedes incomplete v1.3 without overwriting it. U01–U03 definitions and native U04 stage/operator mathematics remain inherited from v1.2. Production CFD is disabled while resource readiness is NO.

`NativeStageObserver.C` appends read-only live geometry and registered native residuals separately from the frozen U04 payload. `server.py` evaluates every native stage, writes compact receipts and passes current state to `live_collector.py`. It emits every physical step's primary scalars, all169 linear component solves, terminal4-transition certificate, controller evidence and bounded U03 histories. QoIs never read saved fields. `ARRIVED` is accepted only at `time_end` and binds the frozen earliest confirmed arrival to native noWriteNow; the mandatory final R2 packet is committed at FINISH. Failed health flushes pending compact evidence and selected raw, then stops without numerical retry. Raw-trigger relative-change alarms are operational diagnostics, never new mass/energy conservation acceptance limits.

`launcher.prepare(spec)` checks contract/input/mesh/source/instrumentation/binary/libraries/compiler/analysis hashes, registered series identity and cap, measured prior permanent footprint, current disk/inodes/RAM and C3 authorization. Each next series requires the earlier valid production series seals in PURGED state. `launcher.run` additionally requires resource-ready YES and an explicit run authorization ID. It preserves byte-exact ordered stdout/stderr using an independent immutable raw log manifest. No preflight invokes purge.

Before sealing, stage archived provenance using `provenance.stage`, produce registered final statistics, then execute `series_validation.validate` via `Series.seal`'s validator. Permanent paths are independently classified; caller-supplied R0/R1/R2-to-R3 overrides are rejected. The seal and purge manifest are exclusive immutable publications. Flat allowlist paths, regular files with one link, private quiescent roots, no symlinks/traversal, SHA/size checks and locked journals are required. Concurrent hostile modification of a directory by its owner is outside this trusted private-directory workflow; isolate ownership before operation. A partial/interrupted purge invalidates normal verification and cannot resume automatically. Manual recovery requires audit and a new authorized operation/revision. Validation failure remains VALIDATING; no seal or purge.

Only `results/routeA/diagnostic_transient/diagnostic_attempt_001/series/<case>` and newly created `preparation/resource_revision_fix/lifecycle_test*` fixtures are eligible roots. Historical results/reviews are outside registered roots. The CLI requires a seal ID, dry-run ID and explicit user authorization ID; no recursive directory deletion exists:

```
python3 lifecycle_cli.py dry-run ROOT --seal-id SHA
python3 lifecycle_cli.py purge ROOT --seal-id SHA --dry-run-id SHA --authorization-id USER_APPROVAL_ID --explicit-user-authorization
python3 lifecycle_cli.py verify ROOT --seal-id SHA
```

R0: complete compact receipts/primary/U01/U03/mass/energy/Co/logs, archived inputs/code, provenance, statistics, comparison outputs, manifests/seals/failure events/journals. R1: every selected full audit, terminal bundle, replay/pressure/sync/mass/energy audit and anomaly raw capture. R2: initial, inherited startup/development/intermediate sampling, arrival candidate/confirmed fields and mandatory final state. R3: explicitly nonselected temporary validation/conversion copies until successful validation and seal. R4: scratch/replay/atomic workspaces. R3+R4 share16GiB, not additive16GiB each; runtime native/backend address-space guards remain8GiB each. Actual target RSS, I/O and compute remain unresolved.

v1.3 already discards nonselected raw only after successful synchronous callback evaluation. That nonexistent on-disk payload has no reclaim credit. Selected R1/R2 never become temporary because they are large. Full nonselected field history is not retained: a later new analysis requiring it may require rerun. Deleted hashes attest historical integrity but cannot recover payload. Rerun uses the sealed input/mesh/source/contract as closely as possible; compiler/CPU/libraries/OS/order/parallelism prevent a promised bitwise identity. Original R0/R1/R2 are never replaced by rerun possibility.

Synthetic tests are not CFD results. Native integration uses four in-memory manufactured cells with145 fv solves/169 components. U03 window tests use separately labelled manufactured scalar histories; they do not claim a native benchmark arrival. The lifecycle test deletes only newly generated synthetic validation copies, preserves every native selected audit/field/log/history and verifies final scalar analysis, selected59 replay and cross-series comparison.
